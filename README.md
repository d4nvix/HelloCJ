# HelloCJ — GTA: San Andreas in Hello Neighbor

**Ah shit, here we go again!**

HelloCJ brings GTA: San Andreas into Hello Neighbor. Play as CJ, explore the Neighbor's house, and experience both games together!

> ⚠️ **Work in Progress:** Expect bugs and unfinished features.

## Installation

1. Download [HelloCJ.zip](https://github.com/d4nvix/HelloCJ/releases/tag/HelloCJ).
2. Extract the archive.
3. Install GTA SA Essential Pack.
4. Run `install.bat` as administrator and select both game folders.
5. Launch using `play.bat`.

## Controls

All movement and gameplay controls are taken directly from **GTA: San Andreas**.

| Key | Action |
|---|---|
| F4 | Open menu |
| F5 | Toggle CJ mode |
| F6 | Jetpack |
| F7 | Spawn a vehicle |
| F8 | Give weapon |
